# 非接触式多模态交互助手 (No-Touch Multimodal Assistant)

### 🌟 愿景：重塑“零接触”智能化交互体验

本系统是一款集成 **计算机视觉 (CV)**、**自动语音识别 (ASR)**、**大语言模型 (LLM)** 与 **语音合成 (TTS)** 的多模态交互演示系统。它通过识别用户的手势动作与语音指令，在无需物理接触的情况下提供智能化、情境化的反馈。

> **应用场景**：智慧医疗病房、数字化会议协作、公共卫生自助终端等等。

---

## 🚀 核心特性

* **多维感知融合**：基于 MediaPipe 的 21 点高精度手势追踪，结合实时语音抓取，实现“手势+语音”的双重交互逻辑。
* **情境化 AI 指挥官**：内置 **会议、医疗、公共终端** 三大预设场景，LLM 会根据当前场景自动调整回复风格与指令优先级。
* **极致视觉反馈**：基于 OpenCV 构建平视显示系统 (HUD)，包含实时手势轨迹、动态粒子效果 (Spark)、环形脉冲 (Pulse) 及比心动画。
* **架构解耦与兼容**：支持 OpenAI 兼容接口（如 DeepSeek, Qwen-ASR 等），并针对 Windows 摄像头后端 (CAP_DSHOW) 进行了优化。

## 🛠️ 技术栈

| 模块 | 技术选型 | 功能说明 |
| :--- | :--- | :--- |
| **视觉引擎** | `MediaPipe` + `OpenCV` | 21 个手势关键点追踪及动态滑动手势检测 |
| **语言大脑** | `DeepSeek` / `OpenAI` | 提供上下文感知的逻辑判断与对话响应 |
| **听觉系统** | `SoundDevice` + `ASR` | 实现音频实时采集与文本转写 |
| **交互界面** | `Pillow (PIL)` | 渲染支持中文字体的高清 HUD 界面 |
| **语音反馈** | `pyttsx3` | 跨平台的本地 TTS 语音合成 |

## 📖 交互指南

### 1. 手势映射与反馈
系统支持单/双手识别，并内置了手势平滑算法：

| 手势 | 典型指令 (会议/医疗/终端) | 视觉特效 |
| :--- | :--- | :--- |
| **左/右滑** | 上一页 / 下一页；菜单切换 | 橙色环形脉冲 |
| **OK** | 确认操作 / 继续 | 青色环形脉冲 |
| **握拳** | 暂停画面 / **紧急呼叫** | 红色火花粒子 |
| **比心** | 触发暖场反馈 / 安抚交互 | 粉色爱心跳动 |
| **五指张开** | 呼出菜单 / 回到主页 | 白色扩展环 |

### 2. 快捷键说明
* `1 / 2 / 3`：切换场景模式。
* `V`：启动语音录制（默认 5s），结合当前手势询问 AI。
* `Space`：冻结/恢复实时画面。
* `S`：保存当前交互瞬间截图。
* `H`：显示/隐藏操作帮助信息。

## 💡 技术亮点：如何解决“误触发”？

在开发过程中，本系统通过 **双重平滑机制** 解决了手势识别的抖动问题：
1.  **时间维度平滑**：引入 `gesture_smooth_window`（滑动窗口滤波），只有当某一手势在连续帧中占据主流时才会被确认为有效指令。
2.  **动作冷却机制**：设置 `gesture_cooldown`，防止在动作过程中产生重复的 AI 请求，确保系统响应的优雅与稳定。
